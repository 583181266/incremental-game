# 像素菜园 · 种菜增量游戏

一款真·像素画风的浏览器种菜增量游戏：所有画面（田园风景、土地、8 种作物的生长过程）都是用代码逐像素绘制的，没有用一张图片。

## 玩法

- **亲手种地**：12 块田地（先开垦 4 块，攒钱解锁更多）。选好种子，点空地播种 → 作物按真实时间生长（种子→嫩芽→成株→成熟）→ 点成熟的作物收获卖钱。点生长中的作物还能浇水催熟。
- **8 种作物**：胡萝卜（3 秒速熟）到黄金麦（20 分钟一茬），种子越贵、长得越久、卖得越狠。
- **自动化农场**：自动播种机（自动往空地播种）、自动收割机（自动收割卖钱）、自动洒水器（全体生长加速），各 8 级。机器齐了，关掉页面也在赚钱（离线按速率结算，上限 8 小时）。
- **像素田园**：页面上方有一整幅像素风景——小屋、果树、篱笆、麦田；每块地里的作物从种子到成熟都是像素画，成熟时还会一蹦一蹦。
- **每日天气**：按日期轮换天气，每天一种作物卖价 +50%。
- **农具与技术**：精钢水壶（浇水 ×3）、堆肥/化肥/星尘肥料（生长 ×1.5）、手套/竹篮/小货车（卖价 +50%）。
- **丰收祭（转生）**：按本季收入的平方根换「金种子」，每颗永久 +5% 卖价。

## 运行

直接用浏览器打开 `index.html` 即可，零依赖。存档在浏览器 localStorage，每 5 秒自动保存。

### 发布到 GitHub Pages

仓库 Settings → Pages → Source 选 Deploy from a branch、分支 `main`、目录 `/ (root)`，一分钟后即可通过 `https://<用户名>.github.io/incremental-game/` 访问。本仓库已开启，上线地址见仓库主页。

## 技术

单文件 HTML + 原生 JS + Canvas 像素绘制。作物生长用时间戳结算（切后台、关页面都不丢进度），经济系统是经典的增量游戏结构：指数涨价、批量操作、乘区叠加、转生货币。
