# 星核工场 · 增量游戏 MVP

一款浏览器增量（放置）游戏：点击反应堆核心赚金币，购买自动生产者，看着数字滚雪球。

## 玩法

- **点击**中央核心赚金币，带飘字反馈
- **8 级生产者**自动产出，价格按 `基础价 × 1.15^已拥有` 指数上涨
- **批量购买** ×1 / ×10 / ×100 / 买满（含等比数列求和与最大可买计算）
- **14 个升级**：点击强化、单个生产者翻倍、全局翻倍，按进度逐步解锁
- **转生**：按本轮累计收入的平方根获得「星核」，每颗永久 +5% 产量
- **存档与离线收益**：localStorage 自动存档（5 秒一次）；离线按离开时长结算，上限 8 小时
- **大数字格式化**：K / M / B / T … 自动缩写

## 运行

直接用浏览器打开 `index.html` 即可，无任何依赖。

### 发布到 GitHub Pages（得到一个可分享的网址）

1. 仓库 **Settings → Pages**
2. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存
3. 一分钟后访问 `https://<你的用户名>.github.io/incremental-game/`

## 技术

单文件 HTML + 原生 JS。主循环用时间戳差分（切后台回来产量也不丢），数值公式与阶段规划见配套文档《增量游戏开发路线图》（核心循环 → 数值平衡 → 转生 → 内容扩展 → 上线运营）。

后续可扩展：成就系统、第二货币、挑战模式、Decimal 大数库（突破 1.8e308 后必需）。
