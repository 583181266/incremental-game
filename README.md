# 像素菜园 · 种菜增量游戏

一款像素风的浏览器种菜增量（放置）游戏：点地采摘、买地种菜，看着小菜园滚成大农场。

## 玩法

- **像素风画面**：硬阴影、方块边框、土块棋盘格田地，点击采摘会蹦出随机蔬菜
- **8 种作物**：胡萝卜、卷心菜、番茄、玉米、南瓜、西瓜、草莓、黄金麦，每种都有自己的故事（见游戏内「菜园图鉴」）；买地价格按 `基础价 × 1.15^已拥有` 指数上涨
- **每日天气**：按日期轮换天气，每天有一种作物「大丰收」产量 +50%
- **批量买地** ×1 / ×10 / ×100 / 买满（含等比数列求和与最大可买计算）
- **14 项农具与技术**：锄头镰刀强化采摘、有机肥/滴灌/收割机让单种作物翻倍、菜市场摊位到出口订单让全园翻倍
- **丰收祭（转生）**：按本季累计收入的平方根换「金种子」，每颗永久 +5% 产量
- **存档与离线收益**：localStorage 自动存档（5 秒一次）；你不在时菜园照常生长，离线收益上限 8 小时
- **大数字格式化**：K / M / B / T … 自动缩写

## 运行

直接用浏览器打开 `index.html` 即可，无任何依赖。

### 发布到 GitHub Pages（得到一个可分享的网址）

1. 仓库 **Settings → Pages**
2. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存
3. 一分钟后访问 `https://<你的用户名>.github.io/incremental-game/`

## 技术

单文件 HTML + 原生 JS。主循环用时间戳差分（切后台回来产量也不丢），数值公式与阶段规划见配套文档《增量游戏开发路线图》（核心循环 → 数值平衡 → 转生 → 内容扩展 → 上线运营）。

后续可扩展：成就系统、第二货币、挑战模式、Decimal 大数库（突破 1.8e308 后必需）。
